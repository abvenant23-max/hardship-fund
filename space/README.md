# Hardship Fund

A demo of the household hardship allocation platform: dashboard, data entry,
human review, funding cycles, model cards and an admin console. Sign in to
use it; all data is synthetic.

This Space is published from the project's GitHub repository by
`deploy/push_space.py`. Change the code there, not here. It uses the Gradio
SDK only as a Python runtime: `app.py` starts the platform's own FastAPI
server on port 7860.
